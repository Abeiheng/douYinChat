# douYinChat · 抖音直播弹幕助手

一款轻量的桌面弹幕工具，支持窗口置顶、主题换肤、手动回复和关键词自动回复。

**适用于 Windows 10 / 11（64 位）＋ Chrome 浏览器。**

[下载安装](https://github.com/Abeiheng/douYinChat/releases) · [使用方法](#使用方法) · [问题反馈](https://github.com/Abeiheng/douYinChat/issues)

## 下载安装

### 1. 下载并安装软件

打开 [GitHub Releases 下载页面](https://github.com/Abeiheng/douYinChat/releases)，选择最新版本，在 **Assets（资源）** 中下载：

| 文件                                  | 用途                               |
| ------------------------------------- | ---------------------------------- |
| `douyin-版本号-windows-x64-setup.exe` | 桌面软件安装包，双击后按向导安装   |
| `douyin-extension-版本号.zip`         | 浏览器扩展，下载后解压到固定文件夹 |

无需安装开发环境，安装完成后从桌面快捷方式启动「弹幕」。当前安装包未配置数字签名，安装时可能显示未知发布者，请确认文件来自本仓库。

> 如果下载页暂无版本或附件，说明安装包尚未公开发布，请等待后续更新。

### 2. 安装浏览器扩展

1. 在 Chrome 地址栏输入 `chrome://extensions`，打开扩展管理页面。
2. 开启右上角的 **开发者模式**。
3. 点击 **加载已解压的扩展程序**，选择刚才解压得到的 **extension 文件夹**。
4. 将「弹幕 · 抖音直播助手」固定到浏览器工具栏，方便使用。

扩展加载后，请保留该文件夹，不要移动或删除。桌面安装包与浏览器扩展需要分别安装。

### 3. 连接直播间

1. 启动桌面软件，点击顶部 **齿轮 → 连接 → 连接扩展**，点击配对码复制。
2. 打开浏览器扩展，展开 **连接桌面端**，粘贴配对码并点击 **配对**。
3. 在 Chrome 打开正在直播的 [抖音直播间](https://live.douyin.com)，保持登录状态。
4. 在该直播页点击浏览器扩展，点击 **开始采集**。
5. 回到桌面软件，在 **设置 → 连接** 中点击 **开始接收**，再点齿轮返回弹幕窗口。

连接成功后，新弹幕会出现在桌面窗口。使用期间请保持桌面软件和直播标签页打开；浏览器扩展的小弹窗可以关闭。

## 使用方法

| 功能       | 如何操作                                                                        |
| ---------- | ------------------------------------------------------------------------------- |
| 窗口置顶   | 点击顶部置顶图标，再点一次取消                                                  |
| 发送弹幕   | 在底部输入内容，按 Enter 或点击「发送」                                         |
| 回复观众   | 右键一条弹幕，选择「回复评论」，输入内容后发送；点击回复对象旁的 × 切回普通消息 |
| 自动回复   | 在设置中添加「关键词 → 回复内容」规则，再开启关键词自动回复                     |
| 查看历史   | 向上滚动暂停跟随，点击「回到最新」恢复                                          |
| 屏蔽与过滤 | 右键弹幕屏蔽用户；在设置中添加过滤词或管理屏蔽名单                              |
| 更换主题   | 在设置中选择喜欢的配色，自动保存                                                |

**自动回复示例：** 关键词填 `补货`，回复填 `明天下午补货，欢迎关注直播间`。收到包含「补货」的新弹幕后，程序会随机等待 **1–10 秒**，并按设置的间隔、用户冷却和每分钟上限决定是否发送。自动回复默认关闭，可随时关闭。

手动回复与自动回复均通过当前登录的抖音账号发送**公开弹幕**。右键回复的发送格式为 `用户昵称,回复内容`。请先核对登录账号和回复规则。

## 常见问题

- **连接了但没有弹幕？** 确认直播正在进行，扩展已配对并「开始采集」，桌面已「开始接收」。程序接收连接后的新消息，不补齐之前的弹幕；目前一次使用一个选中的直播页，暂不支持真实礼物采集。
- **发送后没有出现在直播间？** 检查网页登录状态，确认网页输入框没有未发送的草稿。桌面提交成功不代表平台已确认送达，请在直播页核实，避免重复发送。
- **更新后无法连接？** 安装新版桌面程序；将新版扩展解压并重新加载，再刷新直播页。当前需要手动下载更新。
- **关闭窗口后仍在回复？** 如果开启了「关闭到托盘」，程序仍会在后台运行。请关闭自动回复、停止接收，或通过托盘菜单退出。

遇到其他问题，可在软件顶部的建议入口反馈，或提交 [GitHub Issue](https://github.com/Abeiheng/douYinChat/issues)。请附上问题描述、版本和必要截图，注意遮挡个人信息与配对码。

## 数据安全

- 弹幕通过浏览器扩展传到本机桌面软件，当前未接入项目自建的聊天记录上传服务。直播网页、头像和公开用户资料仍会访问抖音相关服务。
- 不需要向软件提供抖音密码或 Cookie。个人设置和配对码保存在本机，未额外加密，请勿公开配对码或分享完整应用数据目录。
- 卸载桌面软件不会自动移除浏览器扩展；不再使用时，请同时移除扩展。
