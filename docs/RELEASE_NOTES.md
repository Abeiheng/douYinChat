# v0.2.0

这次发布集中修复了直播间采集、入场提醒和消息展示中的几个实际问题：

- 新增入场监听开关，并支持统计本场入场人次。
- 入场事件不再挤占弹幕列表；保留最近入场信息的统计和延迟提醒，短时间多人进入时提示最后一位用户。
- 修复入场提示一闪即逝的问题：提示显示更稳定，新用户进入时直接更新当前提示。
- 相邻的相同弹幕会合并显示为 `×数量`，不同用户发送相同内容也会合并；入场事件不会再打断合并。
- 切换或关闭直播间时清空旧消息、入场统计和延迟提示，避免旧直播间内容残留。
- 桌面端已开始接收时，切换到新的直播间会自动开始采集，不需要再次手动点击。
- 标题栏增加打开直播浏览器入口，优先使用项目专用 Chromium 并自动加载扩展。
- 浏览器页面出现安全验证、滑块验证或人机验证时，通过系统通知和桌面窗口提醒用户处理。
- 未登录或没有明确用户 ID 时不再请求用户头像和资料，减少无效请求及误报。
- 修复用户资料读取失败时的异常提示，完善直播页刷新和关闭状态提示。

发布文件包括 Windows x64 安装包、浏览器扩展压缩包、Windows 使用说明和 SHA-256 校验文件。
